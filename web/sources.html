Sources et dates de vérification

Chaque règle que les outils citent figure ici, avec son texte exact, la source officielle, la date à partir de laquelle elle s'applique et la date à laquelle nous l'avons relue. Aucun outil du site n'écrit une règle de droit ailleurs que dans ce registre : ce qui est affiché aux utilisateurs vient nécessairement de cette liste.

Ce que cette page ne remplace pas. Un texte de loi cité hors de son contexte ne décide pas d'un cas particulier. Les exceptions signalées ci-dessous sont les principales, pas toutes. Pour un litige engagé, une association de consommateurs, un conciliateur de justice ou un avocat reste l'interlocuteur pertinent.

Réformes annoncées, non applicables

Distinguées volontairement. Une règle qui figure dans cette section n'est utilisée par aucun calcul et par aucune orientation du site.

Données publiques utilisées

  • DVF — Demandes de valeurs foncières, DGFiP, publiées sur data.gouv.fr sous licence ouverte. Millésime 2024 : 20 départements, 379 171 transactions retenues après filtrage. Utilisées uniquement pour situer un bien dans son marché local, jamais comme preuve qu'une taxe est juste ou injuste.
  • API Découpage administratif de l'État (geo.api.gouv.fr), fondée sur le Code officiel géographique 2026 de l'Insee — noms et codes des communes. Relevé le 17 septembre 2026 : 34 917 entrées, France métropolitaine, Corse et départements d'outre-mer.
  • Base officielle des codes postaux (La Poste), diffusée par la même API — correspondance commune / code postal. Le Code officiel géographique ne contient aucun code postal : les deux sources sont donc nécessaires, et distinctes.

Comment ce registre est tenu

Le fichier regles.js contient une entrée par règle, avec les champs : texte, source, statut, date d'application, date de vérification, personnes concernées, exceptions. Une règle dont le statut n'est pas « en vigueur » ne peut pas être présentée comme applicable : les outils l'affichent dans un bloc distinct, au futur. Quand une source change, c'est cette entrée qui est mise à jour, et la date de vérification avec elle.
