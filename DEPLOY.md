# Mettre Foncier Juste en ligne

## Ce que je ne peux pas faire à ta place (règle stricte)
Créer un compte, saisir un moyen de paiement, acheter un nom de domaine — même
gratuits. Ces 10-15 minutes sont pour toi ; je fais tout le reste.

## Étape 1 — un compte GitHub (gratuit, 2 min)
1. Va sur https://github.com/signup et crée un compte.
2. Dis-moi juste "c'est fait" — je crée le dépôt et j'y pousse le code
   (`git init`, premier commit) depuis ce dossier.

## Étape 2 — un compte Vercel (gratuit, pas de carte bancaire requise, 2 min)
1. Va sur https://vercel.com/signup et choisis "Continue with GitHub" (ça relie
   directement les deux comptes, plus simple).
2. Une fois connecté, dis-moi "c'est fait".
3. Je te guiderai pour "importer" le dépôt GitHub dans Vercel (3 clics dans
   leur interface) — ça déploie automatiquement le contenu de `web/` sur une
   URL publique du type `foncier-juste.vercel.app`, en HTTPS, gratuitement.
4. **Chaque fois que j'améliore le site et que je pousse le code**, Vercel
   redéploie tout seul — aucune action de ta part après la configuration
   initiale.

## Étape 3 (plus tard, pas maintenant) — un vrai nom de domaine
On en a parlé dans le dossier de recherche : mieux vaut valider qu'il y a une
vraie demande avant de payer pour un `foncier-juste.fr` (~12€/an chez un
registrar comme Gandi ou OVH). Le sous-domaine gratuit `.vercel.app` suffit
largement pour commencer à tester le SEO et partager le lien.

## Étape 4 (quand tu es prêt à vendre) — Stripe
Compte gratuit à créer sur https://dashboard.stripe.com/register. On en aura
besoin pour le paiement du rapport à 29€. Je m'en occupe uniquement une fois
que tu me donnes le feu vert et que le compte existe.

---

**En résumé : deux comptes gratuits (GitHub, Vercel), 5 minutes chacun, aucune
carte bancaire nécessaire pour l'instant. Dis-moi quand c'est fait et je
prends le relais.**
